# Super Inicio

Guia muy simple para volver a ejecutar la aplicacion cuando apagas y enciendes tu ordenador.

## Pasos (modo facil)

1. Enciende tu ordenador.
2. Abre VS Code.
3. Abre la carpeta del proyecto:
   C:\Users\rober\Desktop\Pracicas WEBS\Practicas de robot
4. Abre una terminal en VS Code.
5. Escribe este comando y presiona Enter:

   & "C:\Program Files\nodejs\node.exe" "server/app.js"

6. Espera este mensaje:
   Robot web app listening on http://localhost:3000
7. Abre tu navegador.
8. Entra a:
   http://localhost:3000

Listo. Ya esta funcionando otra vez.

## Para cerrar la aplicacion

1. Ve a la terminal donde se esta ejecutando.
2. Presiona Ctrl + C.

## Si no abre

1. Revisa que escribiste bien el comando.
2. Revisa que estas en la carpeta correcta del proyecto.
3. Repite el comando de arranque.
